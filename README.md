Some tamper monkey scripts

## Installing

### Userscripts (`*.js` / `*.user.js` files)

1. Install the [Tampermonkey](https://www.tampermonkey.net/) extension.
2. Open the Tampermonkey dashboard and click **+** (Create a new script).
3. Delete the template, paste the contents of the script file, and press `Cmd+S` / `Ctrl+S`.
4. Reload the target page.

Or open the file's raw URL (for `*.user.js` files) and Tampermonkey will offer to install it.
